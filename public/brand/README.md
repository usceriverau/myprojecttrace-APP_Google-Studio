# MyProjectTrace Official Brand Assets

Place the official high-resolution transparent PNG logo at:
`/public/brand/myprojecttrace-logo.png`

Recommended dimensions:
- Width: 400px - 800px
- Height: 100px - 200px
- Format: Transparent PNG
- Colorway: Primary Navy (#03225F) and Primary Blue (#054AC6) with Secondary Soft Blue (#7FA0D4)

The application includes an automated graceful text fallback in `src/components/common/BrandLogo.tsx` if the asset is missing or still loading.
